오늘은 BOJ 골드 4, 1027번 고층 건물을 풀어봤습니다.<br>

## 풀이
**문제 조건**:<br>
건물들이 선분으로 주어질 때, 가장 많은 건물을 '볼 수 있는' 건물과 그 건물에서 보이는 건물의 수를 구하는 문제입니다.<br>
자세한 설명은 [이 링크](https://www.acmicpc.net/problem/1027)를 참고해주세요
**풀이**:<br>
선분의 맨 위 점을 이어 일차함수 f(x)으로 만든 뒤에, 그 사이에 있는 건물들 중 꼭대기의 좌표 (x, y)에서 f(x) ≤ y인 건물이 하나라도 있으면 볼 수 없는 건물으로 판정했습니다.<br>
건물의 개수 N이 50 이하이기 때문에 완전탐색이 가능한 범위라 판단하여 완전탐색을 이용합니다. 시간복잡도는 O($N^3$)입니다<br>
**코드**:<br>
```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
 int N;
 cin >> N;
 vector<int> heights(N);
 for (int i = 0; i < N; i++) cin >> heights[i];
 int result = 0;

 for (int i = 0; i < N; i++) {
  int visible = 0;
  for (int j = 0; j < N; j++) {
   if (i == j) continue;

   double a = (double)(heights[i] - heights[j]) / (i - j);
   double b = heights[i] - a*i;
   bool ok = true;

   for (int k = min(i, j) + 1; k < max(i, j); k++) {
     if (a*k + b <= heights[k]) {
      ok = false;
      break;
     }
    }
    if (ok) visible++;
   }

   result = max(result, visible);
 }
 cout << result;

 return 0;
}
```
