오늘은 BOJ 실버 2, 26518번 수열의 극한값을 풀어봤습니다.<br>

## 풀이
**문제 조건**:<br>
초항 $a_1$, $a_2$가 정해져 있고 $a_i = b * a_{i-1} + c * a_{i-2} (i ≥ 3)$이 성립하는 수열 $a$에서 $n$이 무한히 증가할 때 $\frac{a_n}{a_{n-1}}$의 극한을 구하는 문제입니다.<br>
**아이디어**:<br>
비율 $r_n$을 $r_n = \frac{a_n}{a_{n-1}}$으로 두면 점화식에서 $r_n = b + \frac{c}{r_{n-1}}$이 성립합니다. 즉 비율도 점화식을 만족하죠.<br>
극한이 존재한다고 하면 $r = \lim_{n \to \infin}r_n$이라고 합시다. 그러면 $r = b + \frac{c}{r}$입니다. 양변에 $r$을 곱하면 $r^2 = br + c$ 즉 2차방정식입니다.<br>
2차방정식의 해는 $r = \frac{b \pm \sqrt{b^2 + 4ac}}{2}$로 나타낼 수 있죠. 이때 $b, c > 0$이고 $a_1, a_2 > 0$이므로 $r$도 양수여야 합니다. 다시 말해 우리가 구해야 하는 답은 $\frac{b + \sqrt{b^2+4ac}}{2}$라는 말이죠.<br>
**코드**:<br>
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
 long long b, c, a1, a2;
 cin >> b >> c >> a1 >> a2;

 double r = (b + sqrt(1.0 * b * b + 4.0 * c)) / 2.0;
 cout << fixed << setprecision(20) << r << "\n";

 return 0;
}
```
