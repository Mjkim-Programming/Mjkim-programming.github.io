오늘은 Codeforces Round 1050(Div. 4)의 A번 문제인 Sublime Sequence를 풀어봤습니다.

## 풀이
**문제 조건**:<br>
정수 x와 n을 받아 x와 -x를 번갈아 사용해가며 길이 n의 수열을 만들어냄.<br>
이 수열의 합을 구하라.<br>
ex) 1 2 -> 1, -1 / 3 10 -> 3, -3, 3, -3, 3, -3, 3, -3, 3, -3<br>
**풀이**:<br>
n이 2로 나누어떨어지면 합은 무조건 0이 된다. (x와 -x가 서로 상쇄)<br>
n이 2로 나누어떨어지지 않으면 +x가 합이 된다.<br>
**코드**:<br>
```cpp
1. #include <iostream>
2. using namespace std;

3. int main() {
4.   int t;
5.   cin >> t;
6.   while(t--) {
7.     int a, b;
8.     cin >> a >> b;
9.     if(b % 2 == 0) cout << 0 << "\n";
10.    else cout << a << "\n";
11.   }
12.   return 0;
13. }
```
